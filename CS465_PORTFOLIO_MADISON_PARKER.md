# CS 465 Full Stack Development Portfolio

## Madison Parker — Travlr Getaways

This repository contains my CS 465 course work in dedicated branches so the development of the Travlr Getaways full stack application can be reviewed by module.

### Portfolio branches

- `module1` — Initial Node.js/Express application and static customer-facing site
- `module2` — MVC routing, controllers, Handlebars views, and partials
- `module3` — JSON-driven trip data and reusable Handlebars rendering
- `module4` — MongoDB, Mongoose models/schema, and database seeding
- `module5` — RESTful API and API-backed customer travel page
- `module6` — Angular administrator SPA and CRUD functionality
- `module7` — Admin login, Passport/JWT authentication, and protected write endpoints
- `final` — Final source, Module Eight README, testing summary, and written reflection

The completed portfolio README is on the `final` branch and documents the project architecture, JSON/data flow, refactoring decisions, API/security testing, and my course reflection.
